## 已知邊界

- 中斷點恢復時 VAD 的 `h/c` 重置，最多損失一個語音組（≤30 s）。
- `*.rich.json` 的增強結果以 JSONL 為準重建，不污染 SRT。
- C1 在任務 `done` 時原地重寫正式 SRT：只在完整 SRT 上執行一次純函式，`paused` 不重寫、`done` 短路不重複執行，故續跑與完整跑仍逐位元組一致（`tests/test_punct_contract.py` 16/16）。C2 另存講義，不參與主鏈路。
- 詞級 / 說話人增強失敗只回退為行級字幕；SRT 逐組落盤是唯一事實來源。
- 1.7B 的 10 秒上限來自 IR 匯出固定 `T=1000`，放寬會靜默丟字。
- 早期 `Wave1*.patch`、`longform_patch/`、發行版 zip 等歷史交付已全部合併進 main。

## 複驗命令

```bash
python -m compileall -q *.py tests/*.py tools/*.py
for f in webview/js/*.js; do node --check "$f"; done
for t in tests/test_*.py; do python "$t"; done
python tests/test_longform_runner.py --minutes 4.9
python tools/offscreen_render.py --out ./_offscreen_out
python app_webview.py --selftest
```
