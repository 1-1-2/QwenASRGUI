## 未验证（照抄会出事）

| 项 | 为什么没验 | 影响 |
|---|---|---|
| 真实 0.6B / 1.7B INT8 权重加载 | 沙箱无权重，CI 用 mock | 准确率、实际内存峰值没看过 |
| ForcedAligner（约 939 MB）/ diar ONNX | 从未加载 | 卡拉OK 逐字、说话人着色实机效果未知 |
| Windows GUI 实机 | 无桌面环境 | Edge `--app` 窗口、DWM 标题栏配色、EXE 冷启动未复验 |
| 3–5 小时完整任务 | 需要真实权重 + Windows | Wave 1.5 的 OOM 修复只有静态断言 + 远端 CI |
| onedir 冷启动收益 | `--selftest` 只测进程内可测部分 | 启动不再解压 200 MB 是设计推导，**未实测** |
| SmartScreen 信誉累积 | 需要真实下载量 | 未签名，首次运行会有提示 |
| 魔搭兼容端点 | 未连通 | 文档标注为待确认 |
| 上游许可状态 | 上游无 License | `NOTICE` 与 PR 回推的硬门槛 |

## 已知边界

- 断点恢复时 VAD 的 `h/c` 重置，最多损失一个语音组（≤30 s）。
- `*.rich.json` 的增强结果以 JSONL 为准重建，不污染 SRT。
- C1 在任务 `done` 时原地重写正式 SRT：只在完整 SRT 上执行一次纯函数，`paused` 不重写、`done` 短路不重复执行，故续跑与完整跑仍逐字节一致（`tests/test_punct_contract.py` 16/16）。C2 另存讲义，不参与主链路。
- 词级 / 说话人增强失败只回退为行级字幕；SRT 逐组落盘是唯一事实源。
- 1.7B 的 10 秒上限来自 IR 导出固定 `T=1000`，放宽会静默丢字。
- 早期 `Wave1*.patch`、`longform_patch/`、发行版 zip 等历史交付已全部合并进 main。

## 复验命令

```bash
python -m compileall -q *.py tests/*.py tools/*.py
for f in webview/js/*.js; do node --check "$f"; done
for t in tests/test_*.py; do python "$t"; done
python tests/test_longform_runner.py --minutes 4.9
python tools/offscreen_render.py --out ./_offscreen_out
python app_webview.py --selftest
```
