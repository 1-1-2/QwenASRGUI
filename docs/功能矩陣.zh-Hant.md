# 功能矩陣

繁體中文 · [简体中文](功能矩阵.md)

「目前支援」= 有程式碼、有回歸斷言。「遺留未遷移」= 上游 CTk 桌面版有，WebView 版沒有對應入口。
所有回歸均為 mock ASR，見 [驗證邊界](驗證邊界.zh-Hant.md)。

## 轉寫主鏈路

| 功能 | 目前支援 | 說明 |
|---|---|---|
| 單檔 / 批次 / CLI / 區網 API 統一串流 | ✅ | 單一 `LongformRunner`，無長短分支 |
| 增量寫 SRT + JSONL + checkpoint | ✅ | 每組立刻落盤 |
| 中斷點續跑 / 取消保留已完成 | ✅ | 語音組邊界生效，逐位元組一致 |
| 任務指紋不一致則從頭開始 | ✅ | 模型 / 段長 / VAD / 來源檔 / 語言 / 簡繁 / 詞彙 / 提示詞 |
| 5 分鐘試跑（`.trial.srt`） | ✅ | 獨立 task_id，不污染正式中斷點 |
| 切分預檢（只看前 5 分鐘、不跑 ASR） | ✅ | p50/p90/p99、超上限占比、紅黃綠判定 |
| 影片抽音軌（ffmpeg）/ 無 ffmpeg 的 WAV 回退 | ✅ | 標準庫 wave 路徑 |
| 詞級時間軸 / 說話者分離 | ✅ 選用 | `StreamEnhancer` 掛現成 PCM chunk，另存 `*.rich.json`，失敗回退行級 SRT |
| 跨段標點修正 | ✅ 預設寫回 | 任務 `done` 時對完整 SRT 做一次原子重寫；`paused` 不重寫、`done` 短路不重複執行，續跑與完整跑逐位元組一致（A2） |
| 匯出講義 | ✅ 另存 | `*.handout.md` / `.txt`，按停頓分段 |

## 下載與模型

| 功能 | 目前支援 | 說明 |
|---|---|---|
| `models.json` 單一事實來源 | ✅ | 目錄、大小、SHA256、主/備直鏈、鏡像 |
| 多源測速 / 錯誤分類 / 重試退避 / 斷點 | ✅ | 保留 `urllib`，不引入 SDK |
| 內容校驗（LFS pointer / HTML 探測 / SHA256） | ✅ | 未知值顯示「未知」，不拿估計值冒充 |
| 手動下載清單 `.txt` + 外部下載器命令 | ✅ | aria2c / `hf download` / `hfd.sh` |
| 匯入本地模型 + `full_verify()` | ✅ | |
| TLS 憑證驗證降級告警 | ✅ | 不再靜默 `CERT_NONE` |
| SDK（`huggingface_hub` / `modelscope` / `hf_transfer`） | ❌ 明確否決 | 見架構說明 §5 |

## 互動與工程

| 功能 | 目前支援 | 說明 |
|---|---|---|
| 服務端持久批次佇列 | ✅ | 重新整理不丟、失敗隔離、取消、重試、清除 |
| 雙進度（百分比 + 時間/分段/ETA）+ 即時字幕 SSE | ✅ | 前端列表限 200 條，上捲暫停跟隨 |
| 可折疊執行紀錄（後端環形緩衝 + SSE + 還原） | ✅ | 紀錄原文保真，不被 i18n 改寫 |
| 統一按鈕狀態機 | ✅ | 一處計算所有按鈕 disabled |
| 多執行個體保護 | ✅ | 回環埠鎖 + URL 交接，崩潰不留 stale lock |
| 後端動態文案 i18n（簡/繁/英） | ✅ 部分 | 結構化文案本地化；專有名詞與自由文字診斷保留原文 |
| UI 語言穩定枚舉 `hant/hans/en` | ✅ | 舊中文設定值自動遷移 |
| onedir 分層 / 內容定址 manifest / 差量 / 回滾 | ✅ | 使用者資料更新時不動 |
| 首次啟動引導 / 冷啟動基準 `--selftest` | ✅ | selftest 不含視窗與 Edge 啟動 |
| 檢查更新指向本 fork | ✅ | `QWENASR_UPDATE_REPO` 可覆蓋 |

## 遺留未遷移（CTk 桌面版）

| 功能 | 狀態 | 原因 |
|---|---|---|
| 原生 CTk 桌面視窗 | ❌ 停止更新 | `app_webview.py` 是唯一主線 |
| 原生 WebView2 視窗 | ⚠️ 原始碼可選 | `QWENASR_NATIVE_WINDOW=1`；發行包不捆綁 pywebview/pythonnet |
| 字幕驗證編輯器 UI | ❌ 未遷移 | `subtitle_editor.py` 仍在倉庫，WebView 無入口（按鈕隱藏） |
| 錄音頁的麥克風原生選擇 | ⚠️ 部分 | 瀏覽器權限模型不同 |
| 端點 QR / Cloudflare tunnel UI | ✅ 保留 | 復用上游邏輯 |

## 推論側（不再投入）

執行緒數、performance hint、NPU、內顯、多行程已到邊際遞減區。逐 token 依賴鏈下收益為負，
不再改。1.7B 的 `max_chunk_secs = 10` 是 IR 形狀約束，不是策略值。
