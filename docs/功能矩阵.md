# 功能矩阵

简体中文 · [繁體中文](功能矩陣.zh-Hant.md)

「当前支持」= 有代码、有回归断言。「遗留未迁移」= 上游 CTk 桌面版有，WebView 版没有对应入口。
所有回归均为 mock ASR，见 [验证边界](验证边界.md)。

## 转写主链路

| 功能 | 当前支持 | 说明 |
|---|---|---|
| 单文件 / 批量 / CLI / 局域网 API 统一流式 | ✅ | 单一 `LongformRunner`，无长短分支 |
| 增量写 SRT + JSONL + checkpoint | ✅ | 每组立刻落盘 |
| 断点续跑 / 取消保留已完成 | ✅ | 语音组边界生效，逐字节一致 |
| 任务指纹不一致则从头开始 | ✅ | 模型 / 段长 / VAD / 源文件 / 语言 / 简繁 / 词汇 / 提示词 |
| 5 分钟试跑（`.trial.srt`） | ✅ | 独立 task_id，不污染正式断点 |
| 切分预检（只看前 5 分钟、不跑 ASR） | ✅ | p50/p90/p99、超上限占比、红黄绿判定 |
| 视频抽音轨（ffmpeg）/ 无 ffmpeg 的 WAV 回退 | ✅ | 标准库 wave 路径 |
| 词级时间轴 / 说话人分离 | ✅ 可选 | `StreamEnhancer` 挂现成 PCM chunk，另存 `*.rich.json`，失败回退行级 SRT |
| 跨段标点修正 | ✅ 默认写回 | 任务 `done` 时对完整 SRT 做一次原子重写；`paused` 不重写、`done` 短路不重复执行，续跑与完整跑逐字节一致（A2） |
| 导出讲义 | ✅ 另存 | `*.handout.md` / `.txt`，按停顿分段 |

## 遗留未迁移（CTk 桌面版）

| 功能 | 状态 | 原因 |
|---|---|---|
| 原生 CTk 桌面窗口 | ❌ 停止更新 | `app_webview.py` 是唯一主线 |
| 原生 WebView2 窗口 | ⚠️ 源码可选 | `QWENASR_NATIVE_WINDOW=1`；发行包不捆绑 pywebview/pythonnet |
| 字幕验证编辑器 UI | ❌ 未迁移 | `subtitle_editor.py` 仍在仓库，WebView 无入口（按钮隐藏） |
| 录音页的麦克风原生选择 | ⚠️ 部分 | 浏览器权限模型不同 |
| 端点 QR / Cloudflare tunnel UI | ✅ 保留 | 复用上游逻辑 |

## 推理侧（不再投入）

线程数、performance hint、NPU、核显、多进程已到边际递减区。逐 token 依赖链下收益为负，
不再改。1.7B 的 `max_chunk_secs = 20` 是速度与切点质量的折中，由 `app.py` 单点
决定并向下游传三路（VAD 分组 / 低谷切分 / 补零天花板），不是形状约束。
